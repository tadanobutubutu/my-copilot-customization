# 🚀 Building REST APIs with FastAPI

## 🎯 Objective
Learn the basics of creating modern web APIs using the FastAPI framework in Python.

## 📝 Tasks

### Task 1: Create a basic app
**Description:** Initialize a FastAPI application with a root endpoint.
**Requirements:**
- Install FastAPI and Uvicorn
- Create a file named `main.py`
- Define a GET endpoint at `/` that returns a JSON greeting
